Инструменты Инженерной Таксации

⚖️ Лесничий ПРО: Полевой юрист

Автоматизированный комплекс для гослесинспекторов: расчет ущерба по 7 составам лесонарушений (рубки с многопородной ведомостью, пожары с калькуляцией затрат РДС, карьеры по типам почв, свалки, невывоз, захват, ЭСД). Формирование исков, претензий, актов, редактор статей законов и фототаблица А4.
Открыть судебный модуль →

🧭 Электронная буссоль БГ-ХНС

Прибор для замера магнитных азимутов линий, визиров и внутренних углов поворота лесосек с использованием аппаратного компаса и камеры смартфона.
Запустить буссоль

📊 Ведомость МДО лесосек

Инженерная материально-денежная оценка: поштучный перечет деревьев по ступеням толщины, разряды высот, матричная сетка-точковка и официальный альбомный бланк.
Открыть ведомость МДО

📋 Полевой Журнал таксатора

Замена бумажной перечетной ведомости: оперативная точковка деревьев, расчет запаса на гектар и экспорт данных прямо в лесу.
Открыть журнал

🌲 AR Высотомер

Оптический высотомер на базе гироскопа смартфона. Позволяет точно определять высоту растущих деревьев без дополнительных громоздких приборов.
Измерить высоту

📏 Оптическая мерная вилка

Бесконтактный замер диаметра ствола с использованием камеры смартфона и тригонометрических расчетов угла обзора FOV.
Замерить диаметр

👁️ Полнотомер Биттерлиха

Оптический угловой шаблон для оперативного определения суммы площадей поперечных сечений стволов (полноты насаждений) на 1 гектар.
Рассчитать полноту

📷 Юридическая фотофиксация

Впекание точных GPS-координат, времени и номера объекта непосредственно в пиксели снимка делянки для официальных актов проверки.
Открыть фотомодуль

🔥 Пожарный инспектор

Расчет комплексного индекса горимости по Нестерову (ГОСТ Р 57972-2017) и автоматическое исчисление материального вреда по Постановлению № 2464.
