📖 Полевая инструкция

1. Магнитный визир: Наведите вертикальную нить на веху угла делянки. Дождитесь зелёного кольца авиагоризонта (допуск ±12°). Зафиксируйте румб.

2. Фотофиксация: Нажмите «📷 Фотофиксация». Сделайте снимок — координаты, азимут и паспорт выдела вшиваются в кадр.

3. Буссоль (Лимб): Положите телефон на ладонь горизонтально. При фиксации точка ставится по GPS.

4. GPS-Курс: Нажмите «📍 Старт», пройдите 5–10 м по визиру, нажмите «🏁 Зафиксировать вектор». Точки связываются цепочкой.

5. GPS-расчёт расстояний: При методе «GPS» длина считается автоматически.

6. Загрузка KML/KMZ/GeoJSON: Загружайте файлы квартальных сеток из ФГИС ЛК без интернета.

Магнитный режим (Вертикальный визир)

• Съёмка камерой: предназначена для прямой видимости объектов. Телефон вертикально перед глазами.

• Фиксация базиса: кнопка «Фиксация 0°» отслеживает развороты линий и перпендикуляров.

Горизонтальная дисковая буссоль (Лимб)

• Работа по ладони: полное аппаратное дублирование буссоли БГ-1. Телефон лежит горизонтально.

• Авто-точка GPS: при фиксации азимута программа автоматически фиксирует спутниковую точку.

📡 Режим GPS-Курса (По 2 точкам)

• Цепной алгоритм: 1. На столбе нажмите «📍 Старт линии (Т1)». 2. Пройдите 5–10 м вдоль визира. 3. Нажмите «🏁 Зафиксировать вектор». Отрезок заносится в журнал, Т2 → старт для Т3.

• Без магнитных помех: магнитометр не используется. Металл и ЛЭП не влияют.
