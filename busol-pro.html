Полевая инструкция по отводу лесосеки

  1. Оптический визир (Вертикально): Наведите вертикальную нить экрана на веху угла делянки. Дождитесь зеленого уровня авиагоризонта и зафиксируйте румб в журнал.
  2. Электронная буссоль (Горизонтально): Положите телефон горизонтально на ладонь. Совместите верхний торец устройства с вехой. Нажмите кнопку «🔍 Увеличить компас» для крупного лимба.
  3. 📡 GPS-Курс (По 2 точкам): Нажмите «📍 Старт точки», пройдите 5–10 метров по визиру и нажмите «🏁 Зафиксировать вектор». Точки переключаются по цепочке (Т1, Т2, Т3...).
  4. 📡 GPS-расчет расстояний: Нажмите «Сменить метод» ➔ «📡 GPS-расчет». Длина между зафиксированными точками посчитается автоматически со спутника (для Т1 будет прочерк).
  5. 📂 Загрузка KML / KMZ / GeoJSON: Загружайте файлы квартальных сеток и выделов из ФГИС ЛК или лесоустроительных баз прямо на чертёж без подключения к интернету.
  6. ⛶ Полноэкранный планшет: Нажмите «⛶ На весь экран» для комфортной работы прямо по чертежу с увеличенной мини-буссолью в правом углу.

Магнитный режим (Вертикальный визир)

  • Съемка камерой: Предназначена для прямой видимости объектов. Телефон удерживается вертикально перед глазами таксатора.
  • Фиксация базиса: Кнопка Фиксации 0° служит для отслеживания взаимных разворотов линий и перпендикуляров на дисплее.

Горизонтальная дисковая буссоль

  • Работа по ладони: Полное аппаратное дублирование механической буссоли БГ-1. Телефон лежит горизонтально, исключая наклоны.
  • Тактильный отклик и DMS: Показывает точные градусы, минуты, секунды и высоту. При вращении корпус откликается щелчками на главных делениях шкалы.

📡 Режим GPS-Курса (По 2 точкам)

  • Алгоритм:
    1. На стартовом столбе нажмите «📍 Старт линии (Т1)».
    2. Пройдите 5–10 метров вдоль визира. Программа высчитает истинный азимут.
    3. Нажмите «🏁 Зафиксировать вектор» для ввода в журнал. Кнопка автоматически переключится на Т2.
  • Без магнитных помех: Магнитометр и гироскоп не используются. Металл и ЛЭП не влияют!

  • Положение осей: Плавно меняйте наклоны телефона к горизонту и плоскости земли для очистки магнитных шумов.
